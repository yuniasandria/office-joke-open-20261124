## The joke

> I unmuted in standup to share my big idea, forgot it mid-sentence, and just nodded like the silence had been my whole point all along.

## How it works

`main.ts` writes exactly that one line (134 characters) to `/output/entry.txt` and prints it to stdout. It exits 1 if the joke is empty, over 200 characters, or not exactly one line.

Run it with:

```sh
node main.ts
```
